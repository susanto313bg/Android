Penyimpanan Google Spreadsheet Utama
Belum Terhubung

Hubungkan file Google Spreadsheet yang kamu buat di Google Drive sebagai tempat penyimpanan (*database*) permanen aplikasi ini.

Ambil dari URL Google Sheet kamu: https://docs.google.com/spreadsheets/d/[SPREADSHEET_ID]/edit
Digunakan untuk menerima & menyimpan data otomatis dari aplikasi ke Google Sheet kamu secara real-time.
+ Buat File Baru di Google Sheets

Kirim Data Baru ke Google Spreadsheet

Cara Membuat File Baru di Google Sheets

  1. Buka sheets.new untuk membuat file Google Sheet baru.
  2. Beri nama file, misalnya: BEKASI_9930_Database.
  3. Di Sheet1, buat baris judul pada baris pertama: A1: Waktu, B1: User, C1: Kategori, D1: Rincian.
  4. Klik menu Ekstensi (Extensions) > Apps Script, lalu tempel kode berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.user, data.title, data.detail]);
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

*Klik Terapkan (Deploy) > Penerapan Baru > Pilih Akses: "Siapa Saja" (Anyone). Salin URL Web App yang dihasilkan dan tempelkan pada kolom di atas.
